<b>Technologies used for this project:</b>

Kotlin.
Compose for UI.
Navigation.
Koin for DI.
Retrofit.
Coil for images.
Room for caching and saving to favorites functionality.
Coroutines.

Architecture used:

MVVM with Clean Architecture.
